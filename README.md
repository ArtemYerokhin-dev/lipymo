# Lipymo

A landing page for a small homemade food delivery based in Kyiv. Tatyana cooks from her family recipes — dumplings, borscht, stuffed cabbage — handmade every morning. Serhiy handles orders and delivery. Everything arrives as semi-prepared meals with a cooking card, ready in 5 minutes at home.

## Stack

React 18, Vite, Tailwind CSS

## Run locally

```bash
npm install
npm run dev
```

## Features

- Product catalog with category filters and horizontal scroll
- Product detail modal with ingredients
- Cart drawer
- Checkout page with promo code support and payment options
- Reviews section with a submission form (saved to localStorage)
- Fully responsive, mobile first
- Custom cursor (disabled on touch devices)
- Deployed to GitHub Pages via GitHub Actions
